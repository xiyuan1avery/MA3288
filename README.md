# MA3288: epsilon-lenient regret in stochastic bandits

This repository contains the reproducible experiment for comparing UCB1,
fixed-horizon epsilon-UCB1, and anytime alpha-UCB1 under epsilon-lenient
regret.

Start here:

- [Experiment README](experiments/epsilon_ucb_comparison/README.md)
- [Reference figure](experiments/epsilon_ucb_comparison/results/reference/regret_vs_horizon_epsilon_0p09.png)
- [Audited three-run results](experiments/epsilon_ucb_comparison/results/reference/AUDIT.md)

The experiment README states the model, algorithms, exact parameters,
software requirements, reproduction commands, outputs, and the distinction
between proved and proposed regret coefficients.
